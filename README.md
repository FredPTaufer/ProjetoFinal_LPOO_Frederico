# ProjetoFinal_LPOO_Frederico
Sistema de gerenciamento de salão de beleza desenvolvido em Python para pass disciplina de LPOO. Utiliza arquitetura MVC, interface gráfica com Tkinter, banco de dados PostgreSQL e padrões de projeto como DAO, Factory e Strategy. Possui perfis de Administrador e Cliente para gerenciamento de serviços e agendamentos.
